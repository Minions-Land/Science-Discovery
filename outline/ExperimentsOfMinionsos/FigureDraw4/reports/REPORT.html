VIII停止条件 + 后续

"直到没有新的 Action 可以进行,且新 Skill 超过所有 baselines" — 两半都满足。FD5+ 不应再做防御性 Forge,应转向 evidence-collection。

用户给的两个停止条件

  1. 新 Skill 超过所有 baselines — ✅ 满足。17 共有 cell:16 wins + 1 tie + 0 losses。0 cell regressed。
  2. 没有新的 Action 可以进行(with positive expected value) — ✅ 满足。剩余的 1 个 TIE(equation-block 22=22)和 2 个 NEW cell(cns-graphical-abstract / imrad-section 都 22)各受 structural cap 限制:
    • equation-block:Action 13 已部分应用(margin 设了,paperheight 没设);剩余 -2 是 prompting depth 问题,不是 SKILL 问题。强行 Forge 边际 < 1 分。
    • cns-graphical-abstract:hero-style 摘要图本来就 axis 少,palette + caption 都已 ≤ 3。再 Forge 也很难突破。
    • imrad-section:main.tex 缺 -1 fmt 是 fixture-shape 问题不是 SKILL 问题;palette / fonttype=42 对 prose 文档不大适用。

关键 invariant

  • "Skip discipline" 是 reproductive 失败模式。FD3→FD4 看到的所有 silent regression 都是 agent 觉得 "这个 archetype 太简单了,不用走 academic-plotting"。修法是把 non-skippable check 放在 skill graph 的 根(figure-chart-atlas 第一段),不是叶子。
  • Verify, don't trust.Action 8 的 post-save pdffonts 检查把 silent typography failure 变成 hard script abort。这个模式("agent 说做了,脚本证明做了")可推广 — 任何能脚本化的维度(font type / palette CB-safety / page trim / error-bar count)都该有 fail-the-script gate,不是 prose advice。
  • Provenance > polish.每个 action 的 docstring 都引用具体 grader cell + 维度 + score delta。下一轮 Forge 时,rationale 在文件里,不在脑子里。
  • Stop while ahead.+3 vs baseline 之后,边际 ≈ 0,bleed risk → 无穷大。FD5 不应是 14 条 action 的下一轮 Forge,而该是 evidence collection(真用户、真 venue、真 submission)。

FD5+ 该干什么(不该干什么)

  • 该:把 v4 SKILL 套进真实 paper 投稿流水线,收集 reviewer 反馈作为 evidence,而不是再造 grader-as-judge。
  • 该:等到收够 5+ 真实失败 evidence 才决定下一轮 Forge 的 6 条 action。
  • 不该:预测性 Forge — 加规则去 "防止" 还没出现的 regression。FD3→FD4 的教训:防御性规则容易在错的 archetype 上 misfire(比如 network-graph 规则误打 stacked-bar)。
  • 不该:把 cns-paper-discipline 按 venue (Cell / Nature / NEJM) 拆细 — 在没有真实 venue submission evidence 之前,这种拆细只是 over-engineering。

所有 14 条 action 的 per-action provenance 见 CHANGELOG_skill-forge_figdraw4.md。Markdown 版总报告见 REPORT.md。
