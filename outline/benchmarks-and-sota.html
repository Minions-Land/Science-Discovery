AI Auto-Research 基准全景与 SOTA

七十七个公开基准正在同时丈量 AI 在科研流水线里的能力——从想法生成到同行评审，再到论文传播。本文是这张地图：哪里已经饱和、哪里仍是前沿、什么样的系统在赢、什么样的问题还没被解决。

I2026 春季动态

在我们汇总这份报告前的最后六十天里，整张地图被重新画过一次。

本季度的几条主线值得在进入逐项基准之前先讲清楚。第一条是 open-weight 阵营第一次在某个具体基准上反超闭源模型：阿里 Tongyi DeepResearch 30B-A3B MoE 的 Heavy 变体在 BrowseComp 上拿到 69.0%，超过了所有公开报告过分数的闭源 deep-research 系统（arXiv:2510.06135 / 2510.24701）。MoE 的算法账目同时改写了"价格-能力"曲线——总参数 30B、激活 3B，开源协议 MIT。

第二条是 Anthropic 把 RE-Bench 的分数在几周内拉了 60%。Claude Opus 4.6 的单次 RE-Bench（METR 设计的 4 小时 AI 研发任务）跳到 29.8%；4 月 16 日发布的 Opus 4.7 把 SWE-Bench Pro 从 53.4% 推到 64.3%；4 月 7 日的 Mythos preview 在 SWE-bench Verified 上录得 93.9%。OpenAI 已在 5 月 19 日的官方博客宣布 不再把 SWE-bench Verified 当作前沿评测指标——它正式饱和了。

第三条是 Sakana AI Scientist v2 的论文于 2026 年初登 Nature 651 期 914-919 页，这是史上第一份完全由 AI 生成、且通过真实同行评审的稿件。但同期的独立评估（Beel et al., arXiv:2502.14297）依然刺耳：v2 的实验仍有约一半失败，"新颖性判断"会把已有方法误标成新发现。一个有用的提醒是：Nature 的章 ≠ benchmark 的 SOTA。

第四条是 Google DeepMind 在 5 月 19 日 I/O 上把 AI Co-Scientist 的 Hypothesis Generation 接口公开给了独立研究者，姊妹系统 ERA（Empirical Research Assistance）也在同月的 Nature 报告 AI 写的科研代码胜过人类基线。Google 这条线的特点是不报数字、报湿实验复现。

第五条是 AIRA-2（Meta 系，arXiv:2603.26499，3 月）：一个进化-搜索式的 ML 研究 agent，MLE-bench-30 在 24 小时拿到 81.5% 平均百分位、72 小时 83.1%。这是本季度唯一一个跨越 80% 线的 auto-research 基准——所有其他研究类基准（PaperBench、RE-Bench、AutoResearchBench）仍稳稳停留在 30–40% 以下。

本季度新增的七个基准

下面这七个基准在我们之前 73 项的目录之外，发表都在 2026 年第一/第二季度，建议作为下一轮收录候选：

  • DRACO（Perplexity × Harvard，arXiv:2602.11685）：100 个生产级研究任务、10 个领域、40 国资源、专家校准 rubric。Perplexity Max 与 Microsoft Researcher 都已采纳。Leni 报 71.6%，Perplexity 自家 70.4%。
  • AutoResearchBench（arXiv:2604.25256）：Deep Research 与 Wide Research 双任务。本季度最严苛——Opus 4.6 / GPT-5.4 / Gemini 3.1 Pro 在它上面准确率都 不到 10%。
  • AIRS-Bench（与 AIRA-2 同源发布）：超出 MLE-bench Kaggle 范围的前沿研究工程任务。
  • DeepResearch Bench（Ayanami0730）：22 个学科的 deep-research agent 综合评测，Microsoft 与 Z.ai 在对标材料中都使用了它。
  • AgencyBench（GAIR-NLP，ACL 2026 主会，arXiv:2601.11044）：在 1M token 真实上下文下做长程自治 agent 评测，纯压力测试。
  • PRDBench（arXiv:2510.24358）：50 个真实 Python 项目、20 个领域、结构化 PRD 需求。元趋势：基准本身也开始由 agent 自动生产。
  • LiveAgentBench（arXiv:2603.02586）：104 个从社交媒体抓取的真实场景。
本季度结论 Open-weight 在某些特定能力（BrowseComp / SWE-Bench Pro 性价比）上首次超过闭源；SWE-bench Verified 正式饱和退役；前沿的真正战场转移到 SWE-Bench Pro、PaperBench、RE-Bench、HLE、AutoResearchBench 这五个基准上；研究类自治长程任务（>4 小时）仍是最难的一环。

IIMemory 记忆基准

四个基准在丈量对话记忆、跨会话回忆、冲突解决——长期运行研究 agent 的"地基"。

记忆是瓶颈。一个昨天学到的事实今天就忘掉的研究 agent，无法在自己的工作上继续累积。Mem0 在 2026 年的 State of AI Agent Memory 报告中明确指出：今年记忆已经成为有自己专属基准套件的一级架构组件。三篇并行 arXiv 论文（2603.04257 Indexed Experience Memory、2605.03675 Tiered Memory Architecture、2602.22769 Long-Horizon Memory）一致把"有限上下文窗口"诊断为长程任务的核心瓶颈。一个有用的实操信号：所谓"幻觉"，多数其实是 retrieval 错过。

LoCoMo — Long Conversational Memory

arXiv:2402.17753 · Snap Research · 2024

评测超长程对话记忆：5 个 session × 约 300 轮，跨度 30 天以上。题型覆盖单跳、多跳、时序、开放域和对抗性 QA。

SOTA：Mem0 的 token-efficient memory algorithm 综合分 92.5（在 LongMemEval 上 94.4），单次查询约 6,900 tokens。LiCoMemory 在时序推理上 +29.6 分、多跳推理 +23.1 分。

赢家配方：RAG-based 系统（Mem0、MemoryBank）+ 选择性抽取 + 实体链接 + 时序推理 + 记忆衰减。Full-context 基线动辄 100K tokens 一次查询。

MemBench — 多任务 agent 记忆

arXiv:2506.21605 · ACL 2025 Findings

多任务 agent 记忆基准，覆盖 simple / conditional / highlevel / highlevel-rec 四个难度，并设有 Make Noise 污染条件以测鲁棒性。角色 thread 与事件 thread 分离评估。

SOTA：截至 2026-Q1 没有公认的 SOTA。论文在 GPT-4 / Claude 等多模型上做了基线对比，但全文聚焦于框架设计而非排行榜竞争。

赢家配方：强调"有效性 / 效率 / 容量"三维评测，专测对抗噪声下的稳定性。

MemoryAgentBench — 四能力轴评测

arXiv:2507.05257 · ICLR 2026 · 2025

评测四种核心记忆能力：精确检索、test-time learning、长程理解、冲突解决。把长上下文数据集改写为增量多轮交互。

SOTA：没有公认 SOTA。论文在 full-context、RAG 与多个记忆框架（Letta、Mem0、A-MEM、Cognee）上跑了基线，但定位为诊断工具而非排行榜。

赢家配方：146 行覆盖四个能力切片。设计目的是暴露当前记忆系统的弱点而非给它们排序。

MemoryArena

归属未确认 · 2026

无法独立确认它作为标准 benchmark 的身份。检索结果指向 arXiv:2602.16313 Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks，但该论文并未使用 "MemoryArena" 这个名字。

SOTA：若 arXiv:2602.16313 即是它的本体，则该工作聚焦于"多 session 间彼此依赖、agent 必须把经验蒸馏成记忆并跨 session 应用"。无公开排行榜或 SOTA 数字。

赢家配方：用显式任务依赖测试记忆，不走 QA 形式。

观察 LoCoMo 是当前唯一有清晰 SOTA 的记忆基准（Mem0 92.5），其驱动力是 token-efficient 算法。MemBench 与 MemoryAgentBench 是诊断框架，无活跃排行榜。本季度的元趋势是：cost-efficiency（每次查询多少 token）已经被列为正式 SOTA 评分轴。

IIIIdea Generation 想法生成

六个基准衡量科学创造力——从最小上下文 ideation 到 idea→experiment 闭环。

"AI 能不能生成一个值得做的研究想法"——这一问的答案，有两个让人警醒的发现。一是 HindSight 表明 LLM-as-Judge 与论文真实引用影响力之间是负相关（ρ = −0.29）：评委模型对"好想法"的判断和真实学术影响力背离。二是 retrieval-augmented 的单 LLM 系统能让 idea 质量提升 2.5×（p < 0.001）——上下文比模型更重要。

AI-Idea-Bench-2025 已落盘

arXiv:2504.14191 · 2025

测量 LLM 生成的研究 idea 与从 3,495 篇论文中得到的 ground-truth 后续论文之间的对齐度。双指标：与真实后续工作的对齐 + 一般参照判断。

SOTA：暂无公开排行榜；基线包括 GPT-4、Claude，按"是否预测出真实发表的后续工作"评分。
本地：345 MB · test.parquet（3,495 行）+ target_paper_data.json（23 MB find_cite + summary）+ repo 评分脚本
outline/datasets/1.1-idea-generation/AI-Idea-Bench-2025/{data,repo}/
注：31 GB 原始 PDF 全文 ZIP 已按用户要求跳过——元数据已足够跑评测

赢家配方：单 LLM 系统（无 agent 编排）。

HeurekaBench

arXiv:2601.01678 · ICLR 2026

端到端科学共研 agent（co-scientist）评测，落地在真实代码仓库支持的单细胞生物学探索性问题上。考核 idea→experiment 闭环。

SOTA：无公开排行榜；基线显示 open-source LLM agent 加上 critic 模块后能再提 ~22%，缩小与闭源系统差距。

赢家配方：带 critic 模块的多 agent 系统。

HindSight

arXiv:2603.15164 · 2026

"Oracle"式评测：用真实未来论文的引用影响力 + 会议接收来反向打分生成的 idea。

SOTA：无排行榜；关键发现——retrieval-augmented 系统产出的 idea 评分高 2.5×（p<0.001）；LLM-as-Judge 与真实影响力呈负相关（ρ = −0.29）。

赢家配方：带检索的单 LLM 系统。

IdeaBench 已落盘

arXiv:2411.02429 · KDD 2025

用高影响论文的 title/abstract + 引用集，测 LLM 在最少上下文下的研究 idea 能力。两阶段评分：GPT-4o 先按新颖性 / 可行性给排序，再算"Insight Score"相对排名。

SOTA：暂无公开排行榜；基线为 GPT-4o、Claude 等前沿 LLM。
本地：141 MB · kdm-daiict/Ideabench HF 仓库（8 文件）
outline/datasets/1.1-idea-generation/IdeaBench/data/
注：该 HF 仓库描述较简，建议跑评测前与 KDD'25 paper 中的数据集定义对照确认

赢家配方：把单 LLM 配置成"领域研究者画像"。

LiveIdeaBench 已落盘

arXiv:2412.17596 · 2024

从单个关键词出发的发散性思维评测，覆盖 22 个领域、1,180 个关键词。

SOTA：QwQ-32B-preview 的创造性表现 已可与 claude-3.7-sonnet:thinking 持平，尽管二者在通用智力上有差距。LLM 评委组打分轴：原创性 / 可行性 / 流畅度 / 灵活度 / 清晰度。
本地：1.1 GB · v2 release（2025-03-29）+ repo 代码
outline/datasets/1.1-idea-generation/LiveIdeaBench/{data-v2,repo}/

赢家配方：面向推理优化的 open-weight 模型可与顶级闭源持平。

ResearchBench

arXiv:2503.21248 · ACL 2026 Findings

评测 inspiration retrieval、hypothesis composition、hypothesis ranking 三个能力，全部用 2024+ 论文（无污染）。论文发现 LLM 在 inspiration retrieval（OOD 任务）上表现尤其出色，暗示存在新颖知识关联能力。

SOTA：无公开 SOTA；自动抽取流程支持基准持续更新。

赢家配方：单 LLM 系统。

多模态对照（非科研创意）

IDEA-Bench (ali-vilab) 已落盘

arXiv:2412.11767 · 2024 · ali-vilab

区别于 KDD'25 IdeaBench——这条线是专业级图像生成评测，覆盖 100+ 个设计任务（3d 效果、动物属性编辑、image blending、灯光编辑、movie shots、multi-view、image undo、包装渲染等）。

SOTA：论文中横向对比 GPT-4o、Gemini-Imagen、Midjourney、FLUX、Imagen-3。
本地：329 MB · 724 文件，本次会话作为多模态创意基线对照拉取
outline/datasets/1.1-idea-generation/IDEA-Bench-ali-vilab/data/dataset/
注：MinionsOS 当前没有图像生成 deliverable，所以这个 benchmark 仅作交叉对照。
观察 Idea generation 这个赛道呈现一个有反讽意味的格局：retrieval-augmented 单模型 > 多 agent 编排，open-weight 推理模型已经可与闭源顶级模型在创造力维度持平，而 LLM-as-Judge 这个曾经的"廉价裁判"被证明与真实学术影响力反向。

IVLiterature Review 文献综述

七个原始基准 + 本季度新增的 DRACO 与 DeepResearch Bench——但这条赛道至今没有任何饱和。

没有任何文献综述类基准被解决。几个标志性数字摆在一起就能看出来：DeepScholar-Bench 的几何平均分上限是 31%，SciNetBench 的关系感知准确率不到 20%，连 CiteME 这种"给我一段文字、我告诉你引用的是哪篇论文"的简单任务，最佳 agent（CiteAgent，35.3%）和人类基线（69.7%）之间也还有 34 分差距。本季度把这条线推到聚光灯下的，是 Perplexity × Harvard 的 DRACO 与 Ayanami0730 的 DeepResearch Bench——两者都已被 Microsoft Researcher 与 Z.ai 当作对标坐标。

CiteME — 引用归属

arXiv:2407.12861 · 2024

给一段引用别人工作的文字，识别它指向哪篇论文。测的是 citation hallucination rate。

SOTA：CiteAgent（GPT-4o + 搜索/阅读工具）35.3% 准确率。人类基线 69.7%；前沿 LLM 单跑 4.2–18.5%。

赢家配方：带搜索 + 阅读工具的自治 agent，比纯 LLM 高一个数量级。

DeepScholar-Bench

arXiv:2508.20033 · 2025

"活体"研究综合基准：用最近的 arXiv 论文反向生成相关工作章节。评测维度：知识合成、检索质量、可验证性。

SOTA：没有任何系统跨过几何平均 31% 这条线——远未饱和。基线包括 OpenAI Deep Research、open-source 系统、各类搜索 agent。

赢家配方：多步 deep-research agent，但这个基准本身仍是开放挑战。

IDRBench — 交互式深度研究

arXiv:2601.06676 · 2026

带"按需用户反馈"的 deep research：测交互的好处（质量、对齐）与代价（轮数、token 成本）。

SOTA：关键发现——交互对质量与鲁棒性的提升一致性强、且经常压过模型规模带来的差异。在 7 个 SOTA LLM 上做了对比。

赢家配方：带 user-in-the-loop 的多 agent 框架。

LitSearch

arXiv:2407.18940 · EMNLP 2024 · Princeton-NLP

597 个真实 ML / NLP 检索 query。指标：Recall@k + MRR。

SOTA：Dense retriever + LLM rerank 比 BM25 在 recall@5 上 +24.8%，rerank 再 +4.4%。商用搜索引擎落后最佳 dense retriever 多达 32 个 recall 点。

赢家配方：密集检索 + LLM 重排序。

ReportBench

arXiv:2508.15804 · ByteDance · 2025

用已发表的 arXiv 综述当 gold standard，评测 deep research agent 在学术综述生成上的能力。考核被引文献质量与陈述忠实度。

SOTA：没有公开的具体 SOTA 分数；评测过商用 deep-research 系统。

赢家配方：多步 deep-research agent。

ScholarGym

arXiv:2601.21654 · 2026

把 deep research 的"信息收集"阶段单独切出来，2,536 个专家标注 query 跑在 570K 篇论文上。三段式评测：Query Planning、Tool Invocation、Relevance Assessment。

SOTA：迭代式 query 分解相对单 query 检索带来 2.9–3.3× F1 提升。Query Planning + Relevance Assessment 是双重瓶颈，把 proprietary 与 open-source 的能力差异主要体现在这里。

赢家配方：多步迭代 agent。

SciNetBench — 关系感知检索

arXiv:2601.03260 · 2026

在 18M AI 论文上做关系感知检索：自我中心、成对、路径式三类关系理解。指标 graph F1。

SOTA：当前 retrieval agent 在关系感知任务上准确率 < 20%。把关系 ground-truth 显式提供后，综述质量再 +23.4%。

赢家配方：关系感知 retrieval 系统是必需的，但当前没有任何系统做到。

本季度新增（建议收录）

DRACO — Deep Research At-scale

arXiv:2602.11685 · Perplexity × Harvard · 2026

100 个生产级研究任务、覆盖 10 个领域、信息源跨 40 国，专家 rubric 校准。Perplexity Max 的 deep-research 上线即采用，Microsoft Researcher 也已对接。

SOTA：Leni 71.6%，Perplexity 自家 70.4%。

赢家配方：带显式 rubric 的 production-grade deep-research agent。

DeepResearch Bench

github.com/Ayanami0730/deep_research_bench · 2026

22 个独立学科的 deep-research agent 综合评测框架，目前已被 Microsoft 与 Z.ai 在对标材料中使用。

SOTA：当前公开排行榜由 Tongyi DeepResearch、OpenAI Deep Research、Perplexity 三家轮替领先；具体排名随测评批次浮动。

赢家配方：把"deep research"当作模型类来评测，而非把它当作工作流。

观察 本季度的真正变化：deep research 已经从一种工作流，变成一个被显式区分的模型品类——OpenAI 直接出 o3-deep-research 这个独立 SKU，Perplexity / Google（Gemini for Science）/ Microsoft（Researcher）/ 阿里（Tongyi DR）/ Z.ai 都有自己挂名"deep research"的产品线。

❧

VCoding & Experiments 编码与实验

25 个原始基准 + 本季度新增的 AIRS-Bench、AutoResearchBench、PRDBench、AgencyBench——本阶段仍是密度最高的赛道。

这是 auto-research 流水线被跟踪得最密集的一段。SWE-bench 的排行榜每周都在更新，PaperBench、RE-Bench、MLE-Bench 已是 2025–2026 各家系统报告里的"头条数字"。三个分水岭把"已饱和"的基准（SWE-bench Verified、MLAgentBench）和"前沿"基准（PaperBench、MLR-Bench、RE-Bench）分开来：任务时长、捏造（fabrication）风险、与人类的差距。

本季度最重磅的事件是 OpenAI 在 5 月 19 日宣布把 SWE-bench Verified 退出"前沿评测指标"——它正式被认为饱和了。新前沿是 SWE-Bench Pro，Anthropic Opus 4.7 在它上面拿到 64.3%。MLE-bench-30 这条线则被 Meta 系的 AIRA-2 推到 81.5–83.1%，是本季度唯一跨过 80% 线的研究类基准。

软件工程

SWE-bench

arXiv:2310.06770 · ICLR 2024 · Princeton-NLP

2,294 个真实 GitHub issue 解决任务（Python 仓库）。定义了 agentic coding 评测的现代起点。

SOTA：Claude Mythos preview 在 Verified 上 93.9%（2026 年 4 月）。Full benchmark 顶尖模型 ~70–80%。OpenAI 已于 2026-05-19 宣布不再把它当前沿指标。

赢家配方：Claude 系列长期主导。Verified 子集已逼近饱和。

SWE-bench-Pro 已落盘

arXiv:2509.16941 · Scale AI · 2025

XI趋势观察

把所有基准放在一起看，2026 上半年呈现出五条值得记录的曲线。

1. 饱和曲线。SWE-bench Verified 在 6 个月里从 74.9% 一路推到 80.9%，OpenAI 已宣布不再把它当前沿指标。SWE-Bench Pro 接班——闭源顶尖 53–64%（Opus 4.7 64.3%），开源 GLM-5.1 58.4%。其他 auto-research 基准跨过 80% 的极少：MLE-bench-30 是唯一跨过 80% 线的（AIRA-2 81.5–83.1%）。PaperBench、RE-Bench、AutoResearchBench 都仍稳稳停在 30–40% 以下。

2. Open vs Closed 差距。在 MMLU 类评测上几乎归零；在 agent 类基准上 ~5–10 分。GLM-5.1（4 月发布）以 ~7% 的成本逼近 Opus 4.6。GPT-OSS 120B、GLM-5.1、DeepSeek V4、Kimi K2.6 是当前四个前沿级 open weight。Tongyi DeepResearch Heavy 在 BrowseComp 上压过闭源——这是本季度最干净的"open 赢了"信号。

3. "Deep research" 已成模型品类。OpenAI 出 o3-deep-research 这个独立 SKU；Perplexity、Google（Gemini for Science）、Microsoft（Researcher）、阿里（Tongyi DR）、Z.ai 都有自己挂名"deep research"的产品线。它从一种工作流变成一类显式区分的模型。

4. 记忆是瓶颈。Mem0 的 2026 报告把记忆定位成"有自己专属基准套件的一级架构组件"。三篇 arXiv 论文（2603.04257 / 2605.03675 / 2602.22769）一致诊断：有限上下文是长程任务的核心瓶颈。一个有用的实操信号——多数所谓"hallucination"其实是 retrieval miss。

5. 成本-能力开始被列入 SOTA。Token 成本现在是显式 SOTA 评分轴。GLM-5.1 报价 $1.00 / $3.20 per million in/out（Opus 4.6: $15 / $75）——7×–23× 的差距和 benchmark 分数一起被并列引用。Tongyi DR 的 MoE（30B 总参 / 3B 激活）讲的是同一个故事：用激活参数的成本换能力。SWE-1.6 同时领先成本（免费）与速度（950 tok/s）。一个编辑标准——2026 年没有 $/score 列的排行榜表，看起来已经过时。

综合判断 Auto-research 流水线在 2026 上半年的真实状态是：软件工程 + 数据 QA 的"短任务"端基本饱和；研究类长程任务（>4 小时）仍是难解的；记忆与可靠执行是当前最关键的两个待解块。Open-weight 在 cost-performance 维度首次拿到具体优势；闭源仍在能力天花板上领先。MinionsOS 的"成长"应该集中在长程执行可靠性 + 记忆架构这两条线上。
